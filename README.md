# Джарвис для ПК

Локальный голосовой помощник для **Windows 10/11**. Слушает «Джарвис»,
дожидается конца команды и управляет громкостью, воспроизведением, окнами,
приложениями и сайтами. Интернет нужен только для установки и открытия сайтов;
аудио не отправляется на сервер и не записывается на диск.

## Установка приложения на Windows

Сборка с интерфейсом: **[Jarvis-Setup-0.4.1-x64.exe](https://github.com/Troll0Smesh/Test-Ruf-e/releases/download/v0.4.1-preview/Jarvis-Setup-0.4.1-x64.exe)**
(примерно 75 МБ). Это тестовая версия для 64-разрядной Windows 10/11.

1. Запустите установщик и на шаге **«Папка установки»** выберите нужный диск
   и папку, например `D:\Apps\JarvisPC`. Приложение установится для текущего
   пользователя и создаст ярлык «Джарвис». Права администратора не нужны;
   выбранная папка должна быть доступна для записи.
2. Откройте «Джарвис», выберите микрофон и нажмите **«Включить микрофон»**.
3. Скажите «Джарвис, сделай тише». Для проверки без действий включите
   соответствующий флажок — результат появится в журнале.

**Python, модель и библиотеки уже внутри установщика.** Ничего отдельно
устанавливать или скачивать при первом запуске не нужно. Работает без интернета.
При необходимости разрешите доступ к микрофону для классических приложений
в параметрах конфиденциальности Windows.

В окне доступны выбор микрофона, настройка паузы, индикатор входного звука,
журнал последних команд и вкладка **«Функции и команды»**. На ней перечислены
возможности и настраиваются имена для окон, приложений и сайтов. Настройки
сохраняются между запусками. После изменения имён остановите и снова включите
прослушивание, чтобы обновить словарь распознавания. Кнопка
**«Остановить»** закрывает микрофон и освобождает модель распознавания;
закрытие окна завершает помощника. Можно свернуть окно на панель задач,
чтобы продолжить слушать в фоне. Автозапуск не включается.

Установщик не имеет цифровой подписи. Нативная проверка на реальном Windows-ПК
ещё нужна; это не проверенный промышленный релиз. Интерфейс не устраняет
известные ограничения распознавания слова «Джарвис», описанные ниже.

Удаление: «Параметры → Приложения → Джарвис». Пользовательские настройки
в `%LOCALAPPDATA%\jarvis-pc` сохраняются. Исходники сборщика и способы
повторной сборки — в [packaging/README.md](packaging/README.md).
Если предыдущая версия уже установлена на C: и вы хотите перенести её на
другой диск, сначала удалите предыдущую версию, затем установите новую в
выбранную папку. Настройки голосовых команд при удалении сохранятся.

## Запуск из исходников (для разработки)

Нужны 64-битный Python **3.10–3.12** и микрофон. В PowerShell из каталога проекта:

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install .
.\.venv\Scripts\jarvis.exe --download-model
.\.venv\Scripts\jarvis.exe --dry-run
.\.venv\Scripts\jarvis-desktop.exe
```

В режиме `--dry-run` помощник распознаёт речь и печатает предполагаемое действие,
но не выполняет его. После проверки остановите его через **Ctrl+C** и запустите:

```powershell
.\.venv\Scripts\jarvis.exe
```

При первом запуске разрешите доступ к микрофону для классических приложений
в настройках Windows. Права администратора не нужны. Чтобы выбрать микрофон:

```powershell
.\.venv\Scripts\jarvis.exe --list-devices
.\.venv\Scripts\jarvis.exe --device 1
```

## Что говорить

| Команда | Действие |
|---|---|
| «Джарвис, сделай громче» | +10 процентных пунктов |
| «Джарвис, сделай тише» | −10 процентных пунктов |
| «Джарвис, увеличь громкость на двадцать процентов» | +20 процентных пунктов |
| «Джарвис, громкость на пятьдесят процентов» | Установить 50% |
| «Джарвис, выключи звук» / «…включи звук» | Выключить / включить звук |
| «Джарвис, сверни окно» | Свернуть активное окно |
| «Джарвис, сверни все окна» | Свернуть все окна (Win+M) |
| «Джарвис, заблокируй ноутбук» | Заблокировать сеанс Windows |
| «Джарвис, громче на двадцать» / «тише на десять» | Изменить на указанное число процентных пунктов |
| «Джарвис, звук на сорок» / «установи звук пятьдесят процентов» | Установить уровень 40% / 50% |
| «Джарвис, поставь музыку на паузу» / «пауза» | Пауза воспроизведения |
| «Джарвис, продолжить» / «возобновить воспроизведение» | Продолжить воспроизведение |
| «Джарвис, сверни окно браузер» / «разверни окно браузер» | Свернуть / развернуть настроенное окно |
| «Джарвис, открой приложение блокнот» | Открыть выбранный файл `.exe` или ярлык `.lnk` |
| «Джарвис, открой сайт новости» | Открыть сохранённый адрес в браузере |

Также понимает «прибавь/добавь/подними звук на …», «убавь/снизь громкость
на …», «сделай звук тише на …», «выставь уровень звука …», «останови видео»,
«приостанови музыку», «сними с паузы», «продолжай» и вежливое «пожалуйста».
Слова «включи звук» снимают mute; «продолжи музыку» запускает воспроизведение.
Пауза и продолжение используют состояние медиасессии Windows: повторная
«пауза» не возобновляет уже остановленное воспроизведение. Поддержка зависит
от проигрывателя: он должен публиковать медиасессию и поддерживать отдельные
команды паузы и воспроизведения. Если сессии нет, Джарвис сообщит об этом в
журнале. Новый файл или плейлист эти команды не открывают.

Для команд с именами откройте вкладку **«Функции и команды»**, выберите тип,
введите короткое имя и укажите значение. Для окна выберите заголовок из списка
открытых окон или введите его часть; если найдено несколько похожих окон,
помощник попросит уточнить заголовок. Для приложения выберите `.exe` или `.lnk`.
Для сайта укажите полный адрес с `https://`. Затем перезапустите прослушивание.
Голосом можно управлять только именами, внесёнными в эту вкладку.

Поддерживаются также «заблокируй компьютер», «заблокируй экран», «покажи рабочий
стол». Числа — от 0 до 100. Прибавление громкости не снимает режим mute:
после «выключи звук» скажите «включи звук».

Можно говорить слитно: **«Джарвис, сверни окно»**, либо отдельно **«Джарвис»**,
затем команду. В консоли появится «Слушаю…». После **0,8 секунды тишины** помощник
завершает распознавание и выполняет одну команду. Затем снова требуется слово
активации. Если команда не поступила за 10 секунд, активация сбрасывается.
При слишком длинной паузе внутри команды она может завершиться раньше времени;
порог настраивается:

```powershell
.\.venv\Scripts\jarvis.exe --silence 1.2
```

Неизвестные команды, распознанные отрицания, низкая уверенность и пропуски
аудио приводят к отказу от действия. «Отмена» завершает текущую попытку без
действия. Это небольшой фиксированный набор команд, свободный диалог не поддерживается.
Сначала проверьте `--dry-run` на своём микрофоне. В аудиопроверках обнаружено,
что распознавание может пропустить короткое «не» — поэтому не используйте
отрицательные команды («Джарвис, не заблокируй…»): для отмены скажите «отмена».
Ответы пока выводятся текстом, без синтеза голоса.

## Память и устройство

- Одна небольшая русская модель **Vosk**, общая для активации и команды.
  Нет LLM, Whisper, браузера, GPU или отдельной модели wake-word.
- WebRTC VAD отличает речь от тишины; команда исполняется только по финальному
  результату распознавания, а не по частичному тексту.
- Моно PCM16, 16 кГц, блоки по 30 мс. Очередь ограничена 32 блоками (~31 КБ).
  При переполнении текущая команда отбрасывается. Неактивный декодер регулярно
  сбрасывается, если нет пауз.
- Модель: ~44 МиБ загрузки, ~88 МиБ на диске. Загрузка явная (`--download-model`),
  с HTTPS и проверкой закреплённого SHA-256. Хранится вне репозитория:
  `%LOCALAPPDATA%\jarvis-pc\vosk-model-small-ru-0.22`.

Измерения памяти и выполненных проверок приведены ниже. «Минимум памяти» здесь —
практичный компромисс для локальной русской речи, не обещание работы в нескольких
мегабайтах. Для уменьшения потребления не запускайте рядом Jupyter или обучающий
ноутбук: для помощника они не нужны.

## Разработка и проверки

```powershell
.\.venv\Scripts\python.exe -m pip install -e .
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
.\.venv\Scripts\jarvis.exe --dry-run --text "громкость 50"
.\.venv\Scripts\jarvis.exe --dry-run --wav command.wav
```

WAV должен быть PCM16, моно, 16000 Гц и содержать слово «Джарвис» перед командой.
`--text` проверяет только разбор команды и обработчик, без распознавания и слова
активации. Без `--dry-run` текстовые команды и WAV тоже выполняют действия.
Для другой модели или места хранения используйте `--model <каталог>` и при
загрузке, и при запуске.

На Linux можно устанавливать проект и запускать тесты/распознавание с
`--dry-run`; управление рабочим столом реализовано только для Windows.
Для микрофона на Linux требуется системная библиотека PortAudio (`libportaudio2`).

### Что проверено в облачной среде

- Автоматические тесты парсера, состояния прослушивания, пауз/тайм-аутов,
  уверенности распознавания, загрузки модели и обработчиков Windows с моками.
- Загрузка официальной модели, её SHA-256, распаковка и повторное использование.
- Потоковое распознавание с настоящими Vosk и VAD: три отдельных
  синтезированных примера (громкость, блокировка, сворачивание) прошли.
- Потребление одного процесса с моделью и обработкой WAV — примерно **210 МиБ RSS**
  на Linux/Python 3.12. Это измерение, не обещание такого же расхода в Windows;
  работа с микрофоном и Windows COM может добавить память.

Облачная машина работает под Linux: реальный микрофон, громкость, сворачивание
окон и блокировка в Windows здесь не проверялись. Качество на живой речи нужно
проверить на вашем ПК. Синтезированная речь также показывает возможные пропуски
слова активации — в этом случае действие не выполняется. В непрерывной
синтезированной записи с теми же тремя командами прошла только блокировка
(1 из 3): в двух других случаях ASR потерял имя. Устойчивое распознавание
на живой речи пока не подтверждено; это ограничение первой версии.

В репозитории также сохранён исходный `train_wakeword.ipynb`. Это отдельный
эксперимент для Google Colab, он не участвует в запуске помощника. Обучать
собственную модель для этой версии не требуется.
